# 受注

EC サイトで顧客の注文を受け付けてから発送するまでを扱う。

## 用語

**当事者（Party）**:
取引の相手になりうる人または組織。

**個人（Person）**:
当事者のうち、自然人であるもの。

**法人（Organization）**:
当事者のうち、組織であるもの。

**顧客（Customer）**:
当事者のうち、注文を 1 件以上出したもの。
_使わない_: 購入者、クライアント

**注文（Order）**:
顧客が商品の購入を申し込んだ記録。
_使わない_: 購入、トランザクション

**下書きの注文（DraftOrder）**:
注文のうち、まだ確定していないもの。

**確定した注文（PlacedOrder）**:
注文のうち、確定して発送を待つか発送されたもの。

**取り消した注文（CancelledOrder）**:
注文のうち、確定の前後を問わず取り消されたもの。

**発送（Shipment）**:
確定した注文の商品を倉庫から送り出した記録。
