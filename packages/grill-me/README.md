# grill-me

計画・設計を厳しくインタビューして磨き込むためのスキル。ビルド前に計画をストレステストしたいときに使う。

## インストール

```bash
apm marketplace add akmaru/dotagents
apm install grill-me@dotagents
```

## 使い方

スラッシュコマンドで起動する:

```
/grill-me
```

エージェントが計画・設計の各分岐について 1 問ずつインタビューを進め、依存関係を 1 つずつ解消していく。

## スキル一覧

| スキル | 内容 |
|--------|------|
| `grill-me` | 計画・設計を分岐ごとに 1 問ずつ深掘りするインタビュースキル |
